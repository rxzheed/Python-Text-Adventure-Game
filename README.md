**Overview**

This project is a text-based adventure game written in Python where the player progresses through a story by making choices. Each choice affects the direction of the game and leads to different paths or outcomes. The game interacts with the user through the command line, asking for input and responding based on the decisions the player makes.

The goal of the project was to design an interactive experience where programming logic controls the flow of the story. By combining storytelling with programming concepts, the game creates multiple branches that allow the player to explore different scenarios depending on their inputs.

**Purpose**

The main purpose of this project was to practice fundamental programming concepts while building an engaging program. The assignment focused on using conditional logic to control the flow of a program and making decisions based on different types of user input. It also encouraged creativity by requiring the development of a unique storyline and interactive decision points.

**Features**
- Interactive command-line gameplay
- Multiple story paths based on player decisions
- Nested decision points that create branching storylines
- Use of different types of input such as integers, floats, and strings
- Story elements that incorporate the user's input into the narrative
- Multiple possible outcomes depending on the choices made

**Programming Concepts Used**

This project demonstrates several foundational programming concepts, including:
- User input and output using input() and print()
- Conditional statements (if, elif, else) to control story progression
- Boolean operators such as and, or, and not
- Comparisons between integers, floats, and strings
- Nested decision structures that create multiple story branches
- Logical conditions that determine different outcomes
