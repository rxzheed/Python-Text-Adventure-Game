# Name: Blackwater Tavern Mystery
# Purpose: Run a mystery investigation game where the user identifies the murderer
# Parameters: none
# Return: Win or lose ending based on the user's final accusation

1: Display the opening story to the user.
    "Music and laughter echoes through the lodge of the Blackwater Tavern..."

2: Display the three suspects to the user:
    - Ashe the Security Guard
    - Marshall the Wallflower
    - Kaido the Grunt

3: Prompt the user with an inner monologue.
    "Hmm, which one should I start with?"
    a. Validate input — must be Ashe, Marshall, or Kaido.
    b. If invalid, print an error and reprompt.

4: Display one clue about the chosen suspect.
    a. Track which suspects have already been investigated.

5: Prompt the user to choose their next action:
    (a) Investigate another suspect
    (b) Inspect Blueno's crime scene for a new clue
    (c) Make a final accusation
    - Validate input — must be a, b, or c.
    - If invalid, print an error and reprompt.

6: Based on the user's choice:
    If (a):
        - Show only suspects not yet investigated.
        - If all suspects have been investigated, inform the user
          and only offer options (b) and (c).
        - Display one clue about the newly chosen suspect.
        - Return to Step 5.
    If (b):
        - Display a new clue from Blueno's crime scene.
        - Track clues already given to avoid repeats.
        - Return to Step 5.
    If (c):
        - Proceed to Step 7.

7: Prompt the user to make their final accusation.
    "Who do you think attacked Blueno?"
    - Must be Ashe, Marshall, or Kaido.
    - Validate input — if invalid, reprompt.

8: Evaluate the accusation.
    - If accusation == "Kaido": display the winning ending.
    - Else: display the losing ending.

9: End.
